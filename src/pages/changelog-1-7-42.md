## 🛠️ 수정 및 조정

### 레시피 & 제작

- **바닐라 상자:** 일반 바닐라 상자 제작이 다시 가능해졌습니다.
- **커스텀 나무 상자:** 바닐라가 아닌 나무 상자 변종은 이제 **가운데에 바닐라 버튼 1개(나무 종류 무관) + 주변에 판자 8개**로 제작합니다.
- **호퍼:** 마인크래프트 기본 상자뿐 아니라 **모든 종류의 상자**로 호퍼를 제작할 수 있습니다.
- (CurseForge 전용) **지가르데 코어 1개 → 지가르데 셀 9개** 변환 레시피 추가.

### 포켓몬, 모델 & 라이딩

- **레쿠쟈:** 원래 속도를 완전히 되찾았습니다!
- **너트령:** 모델 문제 수정.
- **메가 번치코:** 모델과 라이딩 위치 모두 수정.
- **제크로무 & 레시라무:** 라이딩 능력치 재조정.
- **테라파고스:** 스폰율과 포획률 수치 조정 및 재밸런싱.
- **히스이 꽁어름:** 월드 스폰 추가.
- **지가르데:** 폼을 바꾸면 기술 배치가 초기화되고 포인트업/포인트맥스 효과가 사라지던 버그 수정.
- **개굴닌자:** 메가개굴닌자의 모델과 라이딩 위치 수정.
- **기타 수정 (Modrinth 전용):** 조타구 이로치 텍스처 적용, 비크티니 V제너레이트 파티클 텍스처 누락 수정, 킬가르도 배틀 애니메이션 수정, 베라카스 텍스처 버그 수정, 어치르돈 라이딩 위치 수정.
- **기타 수정 (CurseForge 전용):** 날뛰는우레 모델 결함 수정.

### 게임플레이, 스폰 & UI

- **스폰 전반:** 같은 포켓몬 2마리가 정확히 같은 자리에 동시에 스폰되지 않도록 조정 (특히 물속).
- **월드 안정성:** 틱 처리 중인 엔티티 오류를 잡아내 월드가 손상되는 크래시를 막는 안전 장치 추가.
- **배틀 UI:** 배틀 중 능력치 변화를 실시간으로 보여 주는 표시 추가.
- **웨이스톤:** 웨이스톤 삭제 시 게임이 튕기던 문제 수정.
- **셰이더:** 시각적 일관성을 위해 일부 셰이더 설정 미세 조정.
- (CurseForge 전용) 리소스팩 메뉴에 누락/깨진 텍스처를 직접 고치는 방법 안내 추가. (“T”를 눌러도 해결되지 않으면 [Discord](https://discord.lumy.fun)에 제보해 주세요!)
