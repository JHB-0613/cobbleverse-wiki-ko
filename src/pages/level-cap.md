## 관동 시리즈 시작하기

트레이너에게 도전하려면 먼저 **관동(KANTO)**이라는 커스텀 시리즈에 들어가야 합니다. 모드팩을 설치하고 새 월드를 만들면 완전히 자동으로 진행됩니다. **트레이너 카드**에서 확인할 수 있습니다.

![트레이너 카드의 관동 시리즈](up:COBBLEVERSE-Kanto-Series-Trainer-Card.jpg)

어떤 이유로 작동하지 않는다면, **가이드북**에도 적혀 있는 다음 명령어로 쉽게 해결할 수 있습니다.

```
/rctmod player set series kanto @s
```

## 시리즈 구성

각 시리즈는 **체육관 관장 8명**, **사천왕 4명**, **챔피언 1명**으로 구성됩니다. 각자 자신의 구조물에서 스폰됩니다.

- **체육관 관장**은 월드에 무작위로 생성되는 각자의 체육관에서 스폰됩니다. 지도 제작자 주민의 지도로 찾을 수 있습니다. → [체육관 찾는 법](find-gyms)
- **사천왕**과 **챔피언**은 **디 엔드**에서만 발견되는 탑에서 스폰됩니다.

모두 쓰러뜨리면 포켓몬을 **레벨 100**까지 키울 수 있습니다. 각 트레이너는 **배지**와 **기술머신**을 떨어뜨리고, 챔피언은 **특별 보상**도 줍니다.

## 레벨 캡

**레벨 캡(25)**은 포켓몬이 도달할 수 있는 **최대 레벨**입니다. 체육관 관장에게 도전할수록 올라갑니다. (1.7.41부터는 트레이너 카드에서 남은 트레이너와 각 트레이너별 레벨 캡을 그래프로 확인할 수 있습니다.)

레벨 캡을 해제하고 싶다면 다음 두 명령어를 사용하세요. 관동 시리즈의 레벨 캡이 비활성화됩니다.

```
/rctmod player set series kanto @s
/rctmod player set progress after kanto_champion_blue
```
