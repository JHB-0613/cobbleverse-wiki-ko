COBBLEVERSE 정식 버전을 설치하려면 먼저 **Modrinth App**을 내려받아야 합니다. 모드팩 관리를 아주 쉽게 해 주는 최신 런처입니다.

[Modrinth 공식 웹사이트](https://modrinth.com/app)에서 사용 중인 운영체제(Windows, macOS, Linux)에 맞는 버전을 내려받은 뒤, 다른 프로그램처럼 설치하면 됩니다.

> [!WARNING] COBBLEVERSE는 **Windows**에서 원활하게 동작하도록 설정되어 있습니다. macOS나 Linux에서도 작동할 수는 있지만 완전한 호환성이나 지원을 보장하지 않으니 주의하세요.

![Modrinth App 화면](up:Modrinth-App-Screen-How-To-Install-cobbleverse-from-Modrinth-1024x466.jpg)

## 설치 순서

1. Modrinth App을 설치한 뒤 런처를 실행합니다.
2. 처음 실행하면 **Microsoft 계정**으로 로그인하라는 안내가 나옵니다. 마인크래프트: Java 에디션에 사용하는 계정과 같은 계정으로 로그인하세요.
3. 검색창에 **Cobbleverse**를 검색합니다. 모드팩만 보이도록 **“Modpack” 필터**를 꼭 선택하세요.
4. Cobbleverse를 찾았다면 클릭한 뒤 **Install**을 누릅니다.

![Modrinth에서 Cobbleverse 모드팩 검색](up:Modrinth-App-modpack-Cobbleverse-2-1024x341.png)

이제 끝입니다! 다운로드와 설정은 Modrinth가 모두 자동으로 처리합니다.

## 메모리(RAM) 할당

> [!IMPORTANT] 게임을 처음 실행하기 전에 반드시 **최소 4GB(4096MB) 이상의 RAM**을 할당하세요. 오른쪽 위의 톱니바퀴 ⚙️ 아이콘을 눌러 **설정(Settings)**을 열면 됩니다.

![Modrinth에서 4GB RAM 할당하기](up:Modrinth-How-To-Allocate-4-GB-RAM-1-1024x597.jpg)

이 정도 메모리를 할당해야 모드팩이 성능 문제 없이 부드럽게 동작합니다. (1.7.41부터는 4GB에서도 플레이할 수 있도록 최적화되었지만, 쾌적한 플레이를 위해 6GB 이상을 권장합니다.)
